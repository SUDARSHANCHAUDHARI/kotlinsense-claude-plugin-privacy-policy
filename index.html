This Privacy Policy applies to the KotlinSense Claude Code plugin, developed by SUDARSHANCHAUDHARI / SudarshanTechLabs.

What KotlinSense Does

KotlinSense is a Claude Code plugin that connects Claude Code to the kotlin-language-server binary running locally on your machine. It provides real-time Kotlin code intelligence — type error diagnostics, import resolution, and null safety checks — injected directly into Claude's context as you edit .kt and .kts files.

Data Collection

KotlinSense does not collect, transmit, or store any user data. Specifically:

  • All code analysis happens locally via kotlin-language-server running on your machine
  • No source code, file contents, or diagnostics are sent to any external server by this plugin
  • No analytics, crash reporting, or telemetry is included in this plugin
  • The install scripts download the kotlin-language-server binary directly from GitHub Releases — no data about your machine or project is transmitted

Third-Party Services

KotlinSense itself uses no third-party services. The install scripts download the kotlin-language-server binary from github.com/fwcd/kotlin-language-server — this is a one-time download to your local machine with no ongoing data sharing.
